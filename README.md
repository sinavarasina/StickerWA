## Overview

Sticker WA is an Android application that enables users to browse, preview, create, and import sticker packs directly into WhatsApp. The interface is designed with a flat aesthetic, edge-to-edge support, and responsive layouts for portrait and landscape orientations.

## Features

- Borderless card interface with separate sticker count and size chips.
- Interactive floating sticker preview with background dimming and storage export.
- Custom sticker pack creator with automatic WebP conversion and EXIF orientation handling.
- Multi-selection mode for batch patch submission to author and batch pack deletion.
- In-app Theme Mode (Follow System, Light, Dark) and Flat Color Palettes (Catppuccin, Gruvbox, Monet).
- In-app Language selection (Follow System, English, Bahasa Indonesia).
- In-app update checker querying GitHub Releases.
- Automated CI/CD release workflow with version bumping and asset publishing.
