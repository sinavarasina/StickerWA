# Custom Sticker Packs

## Specifications

Custom sticker packs must meet WhatsApp requirements:
- Format: Static or animated WebP.
- Image resolution: Exact 512x512 pixels.
- File size limit: Under 100 KB per sticker.
- Tray icon: 96x96 pixels, under 50 KB.
- Pack limits: 1 to 30 stickers per pack.

## Creation Workflow

1. Tap the floating add button (+) on the main screen.
2. Provide pack name and publisher name.
3. Select a tray icon image.
4. Select 1 to 30 sticker images from device storage.
5. Tap Create Pack. The application automatically normalizes resolutions and compresses images.

## Submission Workflow

Users can submit their custom packs to the author for upstream inclusion:
1. Long-press a custom sticker pack on the main screen to enter selection mode.
2. Select one or more packs.
3. Tap the email action icon in the top toolbar.
4. An email client will open with an attached git patch bundle pre-filled for sina@sinanonym.my.id.
